# Blockers

Register of the Agentic Build Graph. One row per blocker, each with an **owner** and a **target date**;
a blocker with no owner is written as `Owner: UNOWNED` on purpose (§8 — an unowned risk is unmanaged).
Reference the Linear ID when one exists, and put this row's reference in the Linear issue.
